# Shopware

A Shopware 6 shop that runs locally, that you are allowed to break, and that is back up two
minutes later. The environment for it is **ddev**, the running example a freshly installed
shop called **tydace**.

The four pages build on each other:

1. **[What ddev Is]({{< relref "ddev-basics" >}})** — what it is good for and how it works. Ten
   minutes, after which the rest makes sense.
2. **[Installing ddev]({{< relref "ddev-install" >}})** — once per machine.
3. **[Setting Up Shopware 6]({{< relref "shopware-setup" >}})** — from an empty directory to a
   configured shop.
4. **[Working With It Daily]({{< relref "ddev-daily" >}})** — the commands you actually need.
